# 📚 本地文档管理器（文档管理器）使用帮助

> 一款基于 Electron 的本地文档管理工具，用于集中管理本地书籍、文档与各类文本文件，支持书库分类、标签管理、全文预览与关键字搜索。它管理的是文档和本地路径的对于关系，可以方便分类、查找、打开它们。

---

## 一、软件介绍

本地文档管理器是一款桌面应用程序（Electron），可以：

- **集中管理** : 本地分散的文档，按"书库"分门别类，可以很容易找到电脑中的想要文档。当文档很多时，不用记文档的具体保存路径了；
- **直接预览** : Markdown、纯文本、代码、HTML、PDF、图片等多种格式，无需打开其他软件；
- **快速查找** : 文档内容关键字，秒级定位；
- **标签体系** : 为文档打标签，按标签过滤与检索，对书库中的文档设置标签，可以分类，便于查找，一个文档可以设置多个标签；
- **导出/导入备份** : 数据保存在本机 `library.json` 中，可**导出/导入备份**当前所有书库到一个json文件中保存，以便以后可以导入。
- **支持常用文档类型** : 它根据文档后缀自动识别文档类型，支持txt文本/md或markdown文档/html/json/Javascript文件js/css/Python文件py/Rust文件rs/各种编程语言文件/PDF/办公软件文档(docx/xslx/pptx)/web链接/文件夹 等等各种文档类型。并支持点击就可以打开它们。类似于浏览器收藏夹功能，但它比浏览器收藏夹仅支持web链接的功能更强大，它能对本地电脑中绝大部分文档进行管理。
- **markdown文档阅读器** : 特别地，它对markdown文档渲染的比较美观，可以当成一个markdown文档阅读器，支持markdown语法解析渲染、开发代码语法高亮、katex公式渲染显示、mermaid图形渲染显示、jsgraph数学图形渲染显示等等。
- **分页与多视图** : 可将正在预览的文档**锁定为分页**（标签页），分页可拖拽排序，也可**拖到右侧/下方形成并列视图**，同时浏览多个文档；支持**功能区（导航区）右键菜单**设置自动隐藏，获得更大的阅读区域。

> 注意：导入新的书库会清空当前所有书库记录，导入前最好先导出备份。

> 注：文档打印的预览功能在Electron应用程序中不支持。一个间接的打印预览方法是，改用浏览器打开该应用的后台服务地址。操作如下：点击帮助菜单中的菜单项 **浏览器管理书库** 在浏览器中打开书库管理界面，找到想要打印的文档，打开，点击打印按钮，此时的打印窗口支持打印预览功能。(或者，点击视图菜单中的**调试日志**菜单项，在打开的窗口中可以看到该应用后台监听地址，例如：http://localhost:33453 ，选择字符串，<kbd>Ctrl+C</kbd> 拷贝这个后台服务链接，用浏览器打开这个链接，就可以看到同样的书库管理界面)。**问题原因**：这是因为Electron 复用了 Chromium 渲染引擎，但没有移植 Chrome 的打印预览 WebUI，所以不支持打印预览。但是大多数浏览器支持打印预览功能。

## 二、界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部工具栏：书库显示/隐藏 · 全屏 · 搜索 · 导出 · 导入          │
├──────────────┬───────────────────────────────────────────────┤
│              │ 功能区（导航区）：书库控制区 / 文档导航区        │
│              │   （右键功能区 → 菜单：自动隐藏开关）           │
│  书库列表     │ 分页标签栏：主页 分页1 分页2 …             │
│  （左侧）     ├───────────────────────┬───────────────────────┤
│              │  主视图                │ 子视图（右/下）         │
│              │  文档列表 / 预览区     │ 分页内容（文件夹等）    │
└──────────────┴───────────────────────┴───────────────────────┘
```

- **左侧书库列表**：显示所有书库，可拖拽调整顺序；点击切换当前书库。
- **功能区（顶部导航区）**：随活动分页显示**书库控制区**或**文档导航区**；在功能区上**单击右键**弹出菜单，可设置**自动隐藏**（见"七、功能区右键菜单与自动隐藏"）。
- **分页标签栏**：主页固定，锁定后的文档生成分页，可点击切换、拖拽排序、拖到右侧/下方形成并列视图（见"六、分页与多视图"）。
- **主视图 / 子视图**：多视图模式下，主视图显示文档列表/预览区，子视图（右侧或下方）显示拖入的分页内容。

## 三、书库管理

### 1. 新建书库
- 点击左侧书库列表顶部的 **`+ 新建书库`** 按钮；
- 输入书库名称，点击 **确定**。

### 2. 修改书库名称
- 选中一个书库后，点击顶部工具栏 **`修改书库名称`**；
- 输入新名称，点击 **确定**。

### 3. 清理书库（删除书库 / 清理文档）
选中一个书库后，点击书库标题栏的 **`🧹 清理书库`** 按钮，弹出清理书库窗口（窗口可**拖动标题栏移动**、用**右下角手柄调整大小**），提供两种模式：

- **删除书库**：信息栏显示"将删除本书库以及书库中所有记录：书库名"；
  - 点击 **确定** 弹出确认窗口，提示 **将删除本书库及所有记录（不删除原始文件）：书库名**，确认后删除书库及其中全部文档记录（**本地文件不受影响**），文档预览区恢复初始状态；
- **清理文档**：显示搜索条件与文档列表（窗口自动调整为固定尺寸 800×600 便于浏览）：
  - **搜索**：按 **文档类型 / 文档标签 / 文档名称** 三个条件过滤（AND 组合）；输入框**为空或输入"所有"时忽略该条件**；支持 `*` 通配符（如 `*笔记*`、`mark*`）；
  - 文档列表每行带复选框，顶部有 **全选** 复选框，并提示"选中的文件记录将被删除"；
  - 点击 **确定** 弹出确认窗口，提示 **将删除本书库（书库名）中选中的 N 条记录（不删除原始文件）**，确认后仅删除选中的文档记录（**不删除本地文件**）。

> 确认窗口中的 **书库名**、**记录数量**、"**不删除原始文件**"提醒均以加重颜色醒目显示，操作前请仔细核对。

### 4. 调整书库顺序
- 直接用鼠标拖拽书库列表项，松手后即完成排序。

## 四、文档管理

### 1. 添加文档
- 先**选择一个书库**（未选择时会提示先新建/选择书库）；
- 点击 **`+ 添加文档`**；
- 填写：
  - **文档名称**：显示名；
  - **文档路径**：可手动输入完整路径，或点击 **浏览...** 打开文件选择窗口；
  - **标签**（可选）：见下方"标签管理"；
- 点击 **确定添加**。

> 支持添加任意类型的本地文件，系统会根据扩展名自动识别类型
> （如 `.md` → Markdown、`.doc/.docx` → Word、`.xls/.xlsx` → Excel、`.ppt/.pptx` → PowerPoint、`.pdf` → PDF、`.py/.js/.java` 等 → 对应代码类型）。

### 2. 编辑文档（属性编辑）
- 在文档列表项右侧点击 **`✏️`**（属性编辑）按钮；
- 弹窗中可修改：**文档名称**、**文档路径**、**标签**；
- **书库名**与**类型**为只读，不可修改；
- 点击 **保存修改**。

### 3. 删除文档
- 在文档列表项右侧点击 **`🗑️`**（删除）按钮，确认后删除（仅移除记录，不删除本地文件）。

### 4. 文档标签管理（添加/编辑弹窗内）
标签下拉列表第一项为 **✏️ 自定义标签**，后面是**当前书库已有的标签集合**：

- **选择已有标签**：从下拉列表选择某个标签，自动加入该文档的标签集合；
- **自定义新标签**：选择"✏️ 自定义标签..."，出现输入框，输入新标签名后点击 **添加**；
  - 标签名仅允许：**字母（a-zA-Z）、数字（0-9）、下划线（_）、短横线（-）和中文**；
  - 非法字符（空格、标点等）会提示且无法添加；
- 文档标签集合中每个标签为**椭圆形背景**，点击其右侧 **✕** 可删除该标签。

### 5. 文件夹文档（文件列表管理）
书库中可添加**文件夹类型**的文档，双击打开后，内容区显示该文件夹内的目录与文件列表：

- **单击**选中列表中的文件/目录，**双击目录**进入下一级（工具栏 **`⬆ 向上`** 返回上一级），**双击文件**按类型打开预览；
- 工具栏提供两个快捷按钮（作用于**当前选中的**文件/目录，未选中时提示"请先选择文件或目录"）：
  - **`📚 添加文档`**：弹出"添加到书库"窗口，将选中的文件/目录加入书库：
    - **书库名**：下拉选择已有书库（自动选中当前书库），或选择"✏️ 自定义书库..."并输入新书库名（不存在则自动新建）；
    - **文档路径 / 分类 / 名称**：按选中项自动分析填入（分类按扩展名识别，目录为"文件夹"）；
    - **标签**：按所选书库自动列出该书库全部标签，可选用或自定义；
  - **`⭐ 临时收藏`**：不弹窗，自动将选中的文件/目录加入 **临时收藏** 书库（不存在时自动创建），无标签。

> **💡 浏览技巧（文件夹分页 + 双视图）**：可将文件夹文档**固定为右视图分页**，再适当**缩小右视图宽度**，然后在分页中浏览目录与文件、双击打开文件，文件内容自动显示在主页——方便**一边浏览文件夹文件列表，一边查看打开的文档内容**。操作步骤详见"六、分页与多视图"第 5 节。

## 五、文档预览

双击文档列表中的文档（或选中后直接点击）即可在预览区打开。

### 1. Markdown 文档
- 使用增强渲染引擎：支持 **代码高亮、行号、复制按钮、KaTeX 公式、mermaid 图表、front-matter 元信息**；
- **内容目录**：点击预览区顶部 **`📋`** 按钮显示/隐藏左侧目录，点击目录项平滑跳转并高亮；
- **主题切换**：点击 **`🌓 主题`** 按钮在浅色/深色间切换（仅影响预览区）。

### 2. 文本 / 代码文档
- 直接以等宽字体显示，长文本可滚动。

### 3. HTML / PDF / 图片
- HTML 在独立 iframe 中预览；PDF 使用内置查看器；图片直接显示。

### 4. 文档关键字搜索（<kbd>Ctrl+F</kbd>）
- 按 **<kbd>Ctrl+F</kbd>** 弹出查找栏；
- 输入关键字，点击 **查找** 或按 **回车**，逐个跳转并高亮命中位置；
- 支持类型：**Markdown、纯文本、各种编程语言文件、HTML**；
- 按 **<kbd>ESC</kbd>** 或点击 **✕** 关闭并清除高亮。(焦点在搜索栏上，按 <kbd>ESC</kbd> 才起作用。)

### 5. 打印
- 点击 **`🖨️`** 打印当前文档内容；
- Markdown/HTML 直接调用预览区打印（保留样式）；PDF 请使用 PDF 查看器自带打印按钮。

> 注：文档打印的预览功能在Electron应用程序中不支持。
一个间接的解决打印预览方法是，改用浏览器打开该应用的后台服务地址。操作如下：点击帮助菜单中的菜单项 **浏览器管理书库** 在浏览器中打开书库管理界面，找到想要打印的文档，打开，点击打印按钮，此时的打印窗口支持打印预览功能。(或者，点击视图菜单中的**调试日志**菜单项，在打开的窗口中可以看到该应用后台监听地址，例如：http://localhost:33453 ，选择字符串，<kbd>Ctrl+C</kbd> 拷贝这个后台服务链接，用浏览器打开这个链接，就可以看到同样的书库管理界面)。**问题原因**：这是因为Electron 复用了 Chromium 渲染引擎，但没有移植 Chrome 的打印预览 WebUI，所以不支持打印预览。但是大多数浏览器支持打印预览功能。


### 6. 打开文件夹
- 点击 **`📂`** 弹出浏览窗口（默认定位到当前文档所在目录）；
- 选择任意文件后按类型打开：文本类在预览区显示，Office 等类型调用系统软件打开。

### 7. 历史记录
- 点击 **`🕘`** 查看最近打开的 Markdown 文档（仅记录名称与路径，按最近访问排序）；
- 点击历史项即可重新打开该文档。

### 8. 全屏预览
- 点击 **`⛶ 全屏`** 将文档内容区域全屏显示，再点一次退出。

## 六、分页（标签页）与多视图

**主页**固定于主视图，是默认工作区：文档列表、文件夹打开的内容都在主页显示。打开文档后，可将当前预览内容**锁定为分页**（标签页），多个分页可同时存在，实现多文档浏览与多视图并列。

### 1. 锁定分页
- 打开任意文档（含文件夹文档）后，点击文档导航区右侧的 **`🔒 锁定`** 按钮，当前预览内容被固定为一个新分页，自动命名"分页1、分页2…"；
- 分页拥有**独立的内容节点**：各自的滚动位置、iframe 状态、渲染方式互不影响；
- 在主页锁定后，主页会切回书库文件列表，新分页保留刚才的文档内容；再次打开文档时内容默认显示在主页。

### 2. 切换与关闭分页
- 点击分页标签即可切换显示；每个视图可同时高亮各自的活动分页；
- 点击分页标签右侧的 **✕** 关闭该分页（主页不可关闭）；
- 分页全部关闭后自动恢复为单视图（仅剩主页）。

### 3. 分页拖拽排序
- 直接拖拽分页标签，可在同一视图内调整分页顺序。

### 4. 多视图（并列视图）
- 将分页标签**拖到主视图内容区的右半区域**（出现右侧虚线框）松手，即在右侧创建并列视图，分页固定到右视图；
- 将分页标签**拖到主视图内容区的下半区域**（出现下方虚线框）松手，即在下方创建并列视图；
- 最多同时保留两个视图（主视图 + 一个子视图）；
- 将子视图中的一个分页拖到另一方位时（右视图与下视图区域方位之间互相拖动），旧子视图的全部分页自动迁入新子视图；
- 拖动视图之间的**分隔线**可调整各视图宽度/高度（最小 60px），当前仅支持竖向分隔线拖拽改变右视图宽度；
- 点击某一视图内任意区域，该视图即成为活动视图，顶部功能区随之指向该视图的活动分页；
- 子视图中分页全部关闭后，该视图自动隐藏，主视图自动占满整个区域。

### 5. 典型用法：文件夹分页 + 双视图
1. 在主页打开一个**文件夹文档**，内容区显示该文件夹的目录与文件列表；
2. 点击 **`🔒 锁定`** 将文件夹列表固定为分页，再把分页标签**拖到主视图右侧**，文件夹列表就固定到了右视图分页中；
3. 拖动**视图分隔线**，把右视图宽度缩小到合适大小（例如 300~400px）；
4. 在右视图分页中：**单击**选中文件/目录，**双击目录**在分页内进入下一级，**双击文件**则切回主页并在主页打开预览；
5. 这样即可**一边浏览文件夹的目录与文件列表，一边在主页查看打开的文档内容**，无需反复切换。

> 说明：文件夹视图中双击目录只在当前视图（主页或所在分页）内导航；双击文件统一切回主页打开，不影响各分页内容。

## 七、功能区右键菜单与自动隐藏

顶部**功能区（导航区）**包括书库控制区（书库标题栏）与文档导航区（文档标题栏），随活动分页自动切换显示。在功能区上**单击鼠标右键**会弹出功能区菜单：

- 菜单项 **`✓ 自动隐藏`** 前有勾选标记，表示当前是否开启自动隐藏，点击即可**开启/取消**；
- **开启自动隐藏后**：功能区默认收起（隐藏），鼠标移动到主区域**顶部约 20 像素**范围内（或悬停在滑出的功能区上）时，功能区自动滑出显示，移开后再次收起——阅读文档时可获得更大的内容区域；
- **取消自动隐藏后**：功能区恢复固定显示，始终可见；
- 点击页面其它位置、按 <kbd>ESC</kbd> 或窗口失焦，右键菜单自动关闭。

## 八、搜索文档

点击顶部工具栏 **`🔍 搜索文档`** 打开搜索窗口，支持四个条件：

| 条件 | 说明 |
|------|------|
| 书库匹配 | 书库名，`*` 或留空 = 所有 |
| 文档类型匹配 | 如 `pdf`、`md`，`*` 或留空 = 所有 |
| 文档名匹配 | 文档名称关键字 |
| 标签匹配 | 标签名，支持 `*` 通配 |

- 书库、类型、标签输入框下方各有下拉列表，第一项为"所有"，选择后自动填入；
- 点击 **搜索** 显示结果；结果项右侧提供 **👁️ 查看 / ✏️ 属性编辑 / 🗑️ 删除** 操作；
- 勾选结果项后可点击 **保存到书库** 批量加入指定书库；
- 再次打开搜索窗口时，上次的条件与结果会保留。

## 九、标签过滤文档列表

1. 选择书库后，点击书库标题栏的 **`🏷️ 标签`** 按钮；
2. 文档列表左侧出现标签面板：第一项 **所有**，后面为该书库全部标签；
3. 点击某个标签，文档列表仅显示带该标签的文档；
4. 点击 **所有** 恢复显示全部文档；
5. 再次点击 **`🏷️ 标签`** 按钮收起面板并恢复全部文档。

## 十三、注意事项

- 文档记录（书库、文档、标签）保存在本机数据目录，**删除书库/文档不会删除磁盘上的原文件**；

- 若无法打开本地文件，请确认路径存在且应用有读取权限。
